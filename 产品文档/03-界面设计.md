# OTD 订单交付平台 · 界面设计

> 版本 v1.0 · 2026-11-15

本文定义视觉、布局、组件和逐页设计。原型 [原型/otd-prototype.html](./原型/otd-prototype.html) 按本文实现，两者不一致时以本文为准并回改原型。视频里能看到的版式标 `〔视频〕`，我们补的标 `〔推断〕`。

---

## 1. 设计原则

| 原则 | 说明 |
| --- | --- |
| 一条线看到底 | 任何单据详情页都能看到「它在主线的哪一步、前后是谁」：顶部「返回上游单据」按钮 + 底部进度时间线 〔视频〕 |
| 状态先于数据 | 详情页头部先给标签（客户、状态、阶段、轮次、风险），再给字段栅格 〔视频〕 |
| 异常要显眼 | 逾期、慢于平均、不合格、护栏不通过一律红色，并写明「超期多少 / 阈值多少」，不只给颜色 〔视频〕 |
| 数字带口径 | KPI 卡副标题写清口径（如「空余率 < 12%」「33 / 68 准时」），看板有「指标口径」入口 〔视频〕 |
| 少跳转 | 列表行内直接给主操作（去处理、催收、登记收款），不必先进详情 〔视频〕 |
| 密度适中 | 中后台信息密度高，正文 14px、表格行高 44–52px，留白靠卡片间距而不是放大字号 〔推断〕 |

## 2. 主题与色彩令牌

### 2.1 实现方式

全部颜色通过 CSS 变量提供，`<html data-theme="brand-red">` 切换；shadcn/ui 的变量（`--primary` 等）映射到同一套令牌。用户可在个人设置里选 7 套主题之一，或用「自定义主色」覆盖 `--primary`（系统自动推导 `--primary-soft` 和悬停色），「恢复默认」回到品牌红 〔视频〕。主题偏好存用户配置（服务端），本地缓存只做首屏加速 〔推断〕。

### 2.2 七套主题

| 主题 | key | --primary | --primary-soft | 侧边栏渐变 from → to | 适用场景（视频说明） |
| --- | --- | --- | --- | --- | --- |
| 品牌红（默认） | brand-red | `#B5121B` | `#FBE9EA` | `#3A1418` → `#5A1F24` | 集团品牌主色 |
| 科技蓝 | tech-blue | `#2563EB` | `#E6EEFD` | `#101B33` → `#1B2D55` | 沉静 · 数据感 |
| 松柏绿 | pine-green | `#2F8F5B` | `#E4F3EA` | `#10241A` → `#1C3A2A` | 柔和 · 制造现场 |
| 琥珀金 | amber-gold | `#A87A1E` | `#F7EFDC` | `#2A2112` → `#43341A` | 稳重 · 经营视图 |
| 藏青蓝 | navy | `#2C4A7A` | `#E5EAF3` | `#121C30` → `#1F2F4D` | 克制 · 汇报场景 |
| 极简白 | minimal-white | `#C8102E` | `#FBE7EA` | `#FFFFFF` → `#FFFFFF`（侧栏深色文字） | 白净底 · 品牌红强调 |
| 暗夜黑 | dark | `#E5484D` | `#3A1D20` | `#0B0D11` → `#12151B` | 深色模式 · 久看不累 |

视频里主题名第一项是「健盛红」，通用版改为「品牌红」，客户部署时可改名和换色值 〔推断〕。

### 2.3 通用令牌

| 令牌 | 浅色主题 | 暗夜黑 | 用途 |
| --- | --- | --- | --- |
| --bg | `#F3F4F6`（极简白 `#FAFAFA`） | `#0F1115` | 页面底 |
| --surface | `#FFFFFF` | `#171A21` | 卡片、表格、弹窗 |
| --surface-2 | `#F8F9FA` | `#1D212A` | 表头、字段栅格底、输入框底 |
| --text | `#1F2329` | `#E6E8EB` | 正文 |
| --text-2 | `#646A73` | `#9AA0AA` | 字段名、副标题 |
| --text-3 | `#8F959E` | `#6B717C` | 占位、禁用 |
| --border | `#E5E7EB` | `#262A33` | 分割线、卡片边 |
| --success | `#1F9D55` | `#3DD68C` | 已完成、合格、通过、绿灯 |
| --warning | `#D97706` | `#F5A524` | 进行中、临近、黄灯、部分收款 |
| --danger | `#DC2626` | `#FF6369` | 逾期、不合格、红灯、受阻 |
| --info | `#2563EB` | `#5B9BFF` | 未到期、信息标签 |
| --radius | `10px` | 同左 | 卡片、弹窗；按钮和输入框 `8px`，标签 `6px` |
| --shadow | `0 1px 2px rgba(16,24,40,.06)` | `none`（用边框） | 卡片 |

### 2.4 状态色映射

| 语义 | 颜色 | 用在哪 |
| --- | --- | --- |
| 已完成 / 已确认 / 合格 / 通过 / 已收款 / 启用 | success | 节点、单据状态、护栏校验 |
| 进行中 / 当前 / 待确认 / 部分收款 / 黄灯 | warning | 当前节点卡底色用 `--primary-soft`，标签用 warning |
| 已逾期 / 不合格 / 受阻 / 红灯 / 高严重度 | danger | 待办、巡检、验货结论 |
| 待启动 / 未到期 / 草稿 | 中性灰 `--text-3` | 后续节点 |
| 不适用 | 灰色虚线边框 + 删除线节点名 | 客户未启用的节点 |
| 客户名、季节、阶段类信息标签 | `--primary-soft` 底 + `--primary` 字 或 info | 详情页头部 |

图表用主色系 + 中性灰；多系列分类色固定为：主色、`#F59E0B`、`#10B981`、`#6366F1`、`#EC4899`、`#14B8A6`，暗色主题下提高亮度 10% 〔推断〕。

## 3. 字体与排版

| 项 | 规范 |
| --- | --- |
| 字体 | 系统字体优先：`-apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", "Segoe UI", sans-serif`；越南语需要带越南语字形的字体（Noto Sans） |
| 数字 | 金额、数量、百分比、日期一律 `font-variant-numeric: tabular-nums`，表格里右对齐 |
| 字号 | 页面标题 20 / 600；卡片标题 15 / 600；详情主标题 20 / 600；正文与表格 14；字段名、副标题 12–13；KPI 数字 28 / 600 |
| 行高 | 正文 1.6，表格单元 1.4 |
| 金额 | 带币种代码或符号：`USD 62,480.00`、`$2.87`、`¥18.33`；万元口径只用于看板并在副标题注明 〔视频〕 |
| 日期 | `YYYY-MM-DD`，带时间时 `YYYY-MM-DD HH:mm`；相对时间（「剩 34 天」「已超 21 天」「今日 18:00 截止」）用于待办和时效 〔视频〕 |
| 单号 | 等宽可选；单号可点击时用主色 |

## 4. 布局

### 4.1 框架 〔视频〕

```
┌──────────┬──────────────────────────────────────────────────────┐
│ Logo     │ ☰  [全局搜索：订单号、客户、款号…]      🔔 38  语言  头像 │  顶栏 56px
│ 产品名   ├──────────────────────────────────────────────────────┤
│          │ 面包屑：订单列表 / PO0010459                            │
│ 今日待办 │ ▌订单详情                         [次按钮] [主按钮]      │  页头
│ 智能助手 │ ┌──────────────────────────────────────────────────┐ │
│ 企划管理 │ │ 卡片                                              │ │
│  · 列表  │ └──────────────────────────────────────────────────┘ │
│ …        │                                                      │
│ 侧边栏   │  内容区，内边距 24px，卡片间距 16px                     │
│ 220px    │                                                      │
└──────────┴──────────────────────────────────────────────────────┘
```

- 侧边栏：宽 220px，可折叠成 64px 图标栏；背景是主题的纵向渐变；一级菜单 + 二级子菜单，当前项为主色实底圆角块 〔视频〕。菜单按权限裁剪，没有权限的分组整组隐藏 〔推断〕。
- 顶栏：折叠按钮、全局搜索（订单号 / 客户 / 款号，回车跳转或出结果面板）、通知铃铛（未读角标）、语言下拉、头像（姓名 + 角色名，下拉含个人设置、退出）〔视频〕。
- 页头：面包屑（详情页才有）+ 标题（左侧 3px 主色竖条）+ 右侧操作按钮组；详情页最左按钮为「← 返回上游单据号」〔视频〕。
- 内容区：自适应宽度，不设最大宽；超宽屏（≥ 1920px）详情字段栅格从 4 列变 6 列 〔推断〕。

### 4.2 栅格与断点 〔推断〕

| 断点 | 宽度 | 侧边栏 | 字段栅格 | KPI 卡 |
| --- | --- | --- | --- | --- |
| xl | ≥ 1440 | 展开 | 4 列 | 一行 4–6 张 |
| lg | 1024–1439 | 展开（可折叠） | 3 列 | 一行 3–4 张 |
| md | 769–1023 | 默认折叠 | 2 列 | 一行 2 张 |
| sm | ≤ 768 | 抽屉 | 1 列 | 一行 1–2 张 |

窄屏页面不允许横向滚动；宽表格在自己的容器里横向滚动，首列（单号）固定。

## 5. 组件

| 组件 | 规格 | 出处 |
| --- | --- | --- |
| KPI 卡 | 标签（12px 灰）→ 数字（28px）+ 单位 → 副标题口径；可带右侧圆形图标、底部细进度条；可点击跳到对应列表 | 〔视频〕今日待办、产能台账、应收、看板 |
| 详情头卡 | 左：款式图（无图时用品类占位图）+「款式图 ｜ 源自客户企划原件」；右：标签行 → 主标题「单号 · 品名」→ 英文名 / 副信息 → 4 列字段栅格；顶部浅主色渐变 | 〔视频〕打样、测试、验货、报价、订单 |
| 字段栅格 | 字段名 12px 灰在上、值 14px 在下；空值显示「—」；长文本跨整行 | 〔视频〕 |
| 进度时间线 | 竖向，序号圆点（已完成主色实心、当前主色描边 + 卡片浅主色底、待启动灰）；每步卡片：标题 + 状态标签 + 一行说明 + 「去处理 →」；可带「用时 / 平均办结 / 慢于平均」 | 〔视频〕订单监控、打样、测试、验货、出货 |
| 闸门节点 | 节点名后加 ◆；闸门未满足时卡片内列出条件清单（✓ / ✗）| 〔视频〕◆ 标记，清单〔推断〕 |
| 状态标签 | 圆角 6px，浅底深字，见 2.4 | 〔视频〕 |
| 红黄绿灯 | 8px 圆点 + 文字；红灯条目整行左侧 3px 红边 | 〔视频〕巡检、待办 |
| 待办条目 | 复选圈 + 动作名 + 单号 + 一行描述（客户 · 款号 · 内容 · 要求日期）+ 右侧时效（红「任务逾期 22 天」/ 橙「今日 18:00 截止」/ 灰「明日截止」）+「去处理」 | 〔视频〕 |
| 数据表格 | 表头 `--surface-2`；行高 48；行悬停浅灰；操作列文字按钮（主色）；底部「共 N 项数据」+ 每页条数 + 页码 + 跳至 | 〔视频〕 |
| 多轮记录表 | 页签切换（内部报价 1 / 客户报价 3），最新一轮带「最新」标签，比对列用红绿字（高 $0.05 / 低 $0.02） | 〔视频〕报价 |
| 金额进度 | 「已收 / 应收」+ 币种 + 百分比 + 细进度条（红色表示逾期未收） | 〔视频〕应收 |
| 筛选栏 | 页头右侧：下拉（季节、品类、客户、状态、结算主体）+ 搜索框 + 重置 + 主按钮 | 〔视频〕 |
| 弹窗 | 宽 560 / 720 / 960 三档；标题 + 关闭；底部右对齐「取消 / 主操作」 | 〔视频〕导入企划、权限、个人设置 |
| 上传区 | 虚线框 + 图标 + 「拖拽或点击上传 PDF / Excel」；上传后显示文件行与识别进度 | 〔视频〕导入企划 |
| 图表 | 柱状（客户分布）、环形（状态分布）、横向条形（排行）、折线（趋势，带均值虚线）；悬停显示数值 | 〔视频〕 |
| AI 诊断卡 | 左侧摘要卡（助手头像、「AI 总结 · 看板名」、标题、范围、数据截点）+ 右侧「结论与建议」编号列表（01–06，每条主结论 + 「优先处理 / 建议关注」标签 + 依据），左侧 3px 主色或琥珀色边 | 〔视频〕三个看板 |
| 空态 | 圆形浅主色图标 + 主提示 + 次提示（「输入订单号后点击搜索…」） | 〔视频〕订单监控 |

按钮层级：主按钮（主色实底，每页最多 1 个）、次按钮（白底描边）、危险按钮（红字或浅红底，如「移除」「删除」）、文字按钮（表格操作）。

## 6. 智能助手形象与悬浮球

- 视频的助手叫「小达」，用集团吉祥物形象 〔视频〕。通用版**不使用该吉祥物**：默认名「OTD 助手」，默认头像是一个主色圆形字母标识；名称、头像、悬浮形象由系统管理员在系统参数里配置，可上传企业自己的吉祥物（PNG / Lottie）〔推断〕。
- 入口两个：侧边栏第二项「智能助手」整页对话；全局右下角悬浮球，点开为右侧抽屉对话（宽 420px），抽屉里的会话与整页共享 〔推断〕。
- 个人设置可调：常驻显示（开 / 关）、大小（滑块 48–96px）、动作随机循环、动作（看向鼠标等，仅动画形象有效）、速度 〔视频〕。
- 整页对话布局：左栏会话列表（「+ 新对话」、最近会话标题 + 时间 + 条数）；右侧消息流；底部输入框（占位「问点什么，例如『今天有哪些需要我跟进的事』」，Enter 发送 · Shift+Enter 换行，「+」添加附件）〔视频〕。
- 回答卡片：可包含 KPI 行、高亮提示条、条形图、折线图、表格、文字结论、操作按钮（「查看订单列表」）；卡片底部固定一行灰字「数据来源 · 截至时间」〔视频〕。助手要执行写操作时显示确认卡（将要做什么 + 影响对象 + 确认 / 取消），确认前不落库 〔推断〕。

## 7. 逐页设计

每页写布局要点和交互，字段清单见需求文档第 7 节，出处见视频解析第 5 节。

### 7.1 登录 〔视频〕
左右分栏：左 60% 品牌区（产品名「OTD 订单交付平台」、一句口号、4 个卖点图标、背景为工厂实景图，可由客户替换），右侧白色登录卡（手机号、密码、记住手机号、忘记密码、登录）。演示环境下卡片底部显示演示账号胶囊（管理员 / 业务员 / 业务经理 / 总经理，点一下自动填入），生产环境隐藏。右上角语言切换。≤ 768px 时品牌区收成顶部横条。

### 7.2 今日待办 〔视频〕
1. 问候横幅（问候语 + 日期星期 + 数据范围；右侧插画可配置）。
2. 4 张 KPI：待办事项、在手订单、打样进行中、近期交期。
3. 两列图表：客户在手订单分布（柱状）｜订单状态分布（环形 + 图例百分比）。
4. 主区：待办事项卡（分组「已逾期 N 项」红点、「今日到期 N 项」橙点、「后续待办 显示 6 / 共 26 · 展开全部」）；右栏 300px：今日重点关注（4 行，数字可点）、近期交期提醒（单号 + 「已超 N 天」）、相关业务动态。
5. 窄屏时右栏落到主区下方。

### 7.3 订单监控 〔视频〕
页头右侧搜索框（订单号）+ 搜索按钮。空态居中提示。搜到后：基础信息卡（4 列：订单号、客户、季节、款号；数量、交期、承做工厂、状态）→ 订单进程卡（「已完成 5 / 10 步 · 当前节点：PO 复核」+ 10 节点时间线）。当前节点卡片浅主色底；受阻节点红边并列出原因（闸门条件未满足 / 红灯巡检命中）；不适用节点灰色虚线。

### 7.4 企划列表与详情 〔视频〕
列表：缩略图列（图片或 PDF 图标）、款号 + 企划号两行、中英文名两行、季节、品类、客户、状态标签、时间、操作。「+ 新建企划」打开导入弹窗：上传 → 列表里该行显示「识别中」红点 → 完成后变「提取完成」。详情：页头按钮「归档 / 保存 / 确认企划信息」；分区卡片「基础信息」「产品属性（客户 Tech Pack，原文 + 译文两列）」「原件与图片」（左侧原件预览、右侧抽取字段，点字段高亮原件位置）〔推断：高亮〕；AI 抽取的字段旁显示置信度点，低置信度字段黄色底，确认前必须逐个过目 〔推断〕。

### 7.5 打样详情 〔视频〕
头卡标签：轮次类型（PROTO）、成本状态、第 N 轮、重打结转次数、进度健康（进度正常 / 慢于平均）。「打样工艺要点」两列（企划译文、纱线配置、工艺要点、打样说明）。「样品进度」卡标题带「交期 · 剩 N 天」，5 阶段时间线，每步显示完成时间 · 地点 · 实际用时，底行「用时 X · 平均办结 Y」，慢于平均时加红标。

### 7.6 测试记录与详情 〔视频〕
列表列：送测单号、客户、PO、款号、品名、机构、项目、阶段、送测日、要求完成、结论、状态。详情头卡同上；「送测进度」时间线（寄样并申请 → 机构检测 → 出具报告 → 归档）。「报告复用校验」卡：列出可复用的历史报告及匹配条件（款式 / 工艺 / 测试项 / 有效期）逐项 ✓ / ✗ 〔推断〕。

### 7.7 报价单详情 〔视频〕

## 8. 多语言排版

- 首发 `zh-CN`、`en-US`，预留 `vi-VN` 〔视频：中英；越南语推断〕。语言切换即时生效，不刷新页面。
- 翻译范围：菜单、标题、按钮、表头、字段名、状态名、提示与错误信息、看板口径说明。业务数据（客户名、品名、单号、备注）不翻译 〔视频〕；企划原件的中英对照是业务数据，单独存储 〔视频〕。
- 英文比中文长 30–60%：按钮不定宽；表头允许两行；侧边栏菜单项超长时省略号 + 悬停提示；KPI 标签最多两行。
- 日期、数字、金额按语言格式化（千分位、小数点），币种代码不变。
- 时效文案用带参数的句式（「任务逾期 {n} 天」/「{n} days overdue」），不拼接。

## 9. 可访问性与交互细节

- 文字与背景对比度不低于 4.5:1（暗夜黑同样要求）；状态不只靠颜色，必须有文字。
- 所有可点击元素可用键盘到达，焦点环用主色 2px。
- 表格支持列宽拖动和列显示设置（记住到用户配置）〔推断〕。
- 危险操作（删除、取消验货、移除模块、停用任务、回退变更）二次确认，弹窗写清影响范围。
- 长任务（AI 识别、同步执行、巡检）显示进度或加载态，完成后通知铃铛提醒。
- 表单校验即时提示；提交失败保留已填内容。
